# Balloon Park

Open **Games → Balloon Pop**. The standalone game uses the existing catalog,
`KidGameShell`, `KidUi`, Cubit state management, and global sound preference.

- Free play: 20 pops or 60 seconds, with no penalty for missed balloons.
- Open Challenge: endless scoring until the child taps Finish. Pops earn 10
  points times a combo multiplier; every five consecutive pops raises it, up to
  ×5. Pop within 2.5 seconds to maintain the streak. A missed balloon or expired
  combo resets the multiplier without subtracting earned points. Every 12 pops
  increases speed and spawn frequency, capped at wave 8. Replay starts at wave 1.
  The HUD shows points, wave, multiplier, pops, and remaining combo time; the
  completion screen summarizes the run. English and Arabic challenge guidance,
  wave announcements, combo celebrations, and finish narration use shared TTS.
- Colors, numbers (1–6), English letters (A–F), and Arabic letters (أ–ح):
  eight matching pops, without a time limit. Each mode uses a small starter set.
- Wrong selections still pop; a gentle voice repeats the unchanged target.
- Replay resets progress. Pause freezes the simulation; returning from the
  background requires an explicit resume. Navigation disposes ticker and audio.
- Maximum nine active balloons, varied lifetimes and sinusoidal drift, and
  transient bursts. Vector illustrations require no raster art or texture loads.
- TTS narration and short effects use separate audio paths, so a quiet pop can
  play under speech. New narration replaces the previous line. Mute and global
  sound changes stop both immediately.

## Audio sources

`assets/audio/balloon/pop.wav` is an original synthesized 140 ms pressure pulse
with a soft noise release, generated by `tool/prepare_balloon_audio.ps1`.

`reward.wav` and `celebrate.wav` are `confirmation_001.ogg` and
`confirmation_004.ogg` from [Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds),
downloaded from [OpenGameArt](https://opengameart.org/content/interface-sounds)
on 2026-10-23. The shipping WAV copies come from [the Calinou lossless conversion](https://github.com/Calinou/kenney-interface-sounds) for iOS compatibility. CC0 license is bundled as `Kenney-LICENSE.txt`.

Spoken prompts use the shared TTS service, which selects an Egyptian Arabic
voice when available. Balloon pop and reward sounds remain bundled effects.

## Verification

```powershell
flutter test test/balloon_pop test/catalog/grid_contents_regression_test.dart
flutter analyze lib/features/BalloonPop test/balloon_pop
flutter test test/balloon_pop/balloon_pop_test.dart --dart-define=BALLOON_PREVIEW=true --plain-name preview
```

The optional preview produces `build/balloon-start.png` and
`build/balloon-playing.png`. Tests cover simulation bounds, drifting, escape,
all target modes, duplicate taps, round completion, replay, mouse input,
mute, pause/lifecycle, disposal, asset paths, and English/Arabic layouts at
360×640, 780×390, and 800×1200.
