# Color Memory Game (لعبة ذاكرة الألوان)

## نظرة عامة (Overview)

لعبة ذاكرة الألوان هي لعبة تعليمية بسيطة تختبر وتحسن قدرة الأطفال على التذكر والتركيز. اللعبة مستوحاة من لعبة Simon الكلاسيكية، حيث يشاهد اللاعب تسلسل من الألوان المضيئة ويحاول إعادة التسلسل بالضغط على المربعات الملونة.

A simple educational memory game that tests and improves children's memory and focus abilities. The game is inspired by the classic Simon game, where players watch a sequence of highlighted colors and try to repeat the sequence by tapping the colored tiles.

## المميزات الرئيسية (Key Features)

### ✅ تم التنفيذ (Implemented)

#### 1. **أوضاع اللعب (Game Modes)**
- **Classic Mode (النمط الكلاسيكي)**: تسلسل يزداد خطوة خطوة مع كل جولة ناجحة
- **Timed Mode (النمط الموقوت)**: كل ضغط يجب أن يكون خلال زمن محدد
- **Endless Mode (النمط اللانهائي)**: استمر حتى الخطأ وسجّل أعلى نتيجة

#### 2. **مستويات متدرجة الصعوبة (Progressive Difficulty Levels)**
- **المستوى 1**: شبكة 2×2، 4 ألوان، تسلسل يبدأ من 3 عناصر
- **المستوى 2**: شبكة 3×3، 6 ألوان، تسلسل يبدأ من 4 عناصر
- **المستوى 3**: شبكة 4×4، 8 ألوان، تسلسل يبدأ من 5 عناصر
- **المستوى 4+**: شبكة 5×5، 8 ألوان، تسلسل يبدأ من 6 عناصر

#### 3. **لوحات ألوان متعددة (Multiple Color Palettes)**
- **Classic**: ألوان زاهية كلاسيكية (أخضر، أحمر، أزرق، أصفر، برتقالي، بنفسجي، سماوي، وردي)
- **Pastel**: ألوان باستيل هادئة
- **Vibrant**: ألوان حيوية ونابضة

#### 4. **واجهة مستخدم جميلة (Beautiful UI)**
- خلفية بيضاء نظيفة (#FAFAFA)
- تأثيرات انتقال سلسة
- رسوم متحركة عند الضغط على الألوان
- تأثير إضاءة (highlight) واضح للألوان
- ظلال وحواف مستديرة

#### 5. **نظام النقاط والإحصائيات (Scoring & Statistics)**
- نظام نقاط ديناميكي: 10 نقاط لكل خطوة صحيحة
- مكافأة 50 نقطة للجولات المثالية
- تتبع أعلى نتيجة محليًا باستخدام SharedPreferences
- عرض الإحصائيات: النقاط، الجولة الحالية، طول التسلسل، أفضل نتيجة

#### 6. **Haptic Feedback (التغذية الراجعة اللمسية)**
- اهتزاز خفيف عند الضغط على الألوان
- قابل للتفعيل/التعطيل من الإعدادات

#### 7. **وضع دعم عمى الألوان (Color-Blind Mode)**
- عرض حرف داخل كل مربع ملون للتمييز
- يساعد الأطفال الذين يعانون من ضعف رؤية الألوان

#### 8. **حفظ محلي (Local Storage)**
- حفظ أعلى نتيجة باستخدام SharedPreferences
- استرجاع النتيجة عند إعادة فتح اللعبة

#### 9. **التكامل مع Level Map (Integration with Level System)**
- اللعبة مدمجة في نظام الخريطة الرئيسي
- ظهورها في التسلسل: Animal Quiz → Memory Game → **Color Memory** → Puzzle → Math Game
- 4 مستويات لكل دورة (20 مرحلة إجمالية)

#### 10. **شاشات حوارية جميلة (Beautiful Dialogs)**
- **Success Dialog**: تظهر عند إكمال الجولة بنجاح
- **Game Over Dialog**: تعرض النتيجة النهائية والإحصائيات
- تصميم عصري مع أيقونات ملونة

## البنية المعمارية (Architecture)

### BLoC Pattern
اللعبة تستخدم نمط BLoC (Business Logic Component) لإدارة الحالة:

```
ColorMemoryGame/
├── bloc/
│   ├── color_memory_bloc.dart      # منطق اللعبة الرئيسي
│   └── color_memory_event.dart     # أحداث اللعبة
├── data/
│   └── models/
│       ├── color_memory_constants.dart  # الثوابت واللوحات اللونية
│       └── game_state_model.dart        # نماذج البيانات والحالة
└── UI/
    ├── color_memory_screen.dart    # الشاشة الرئيسية
    └── widgets/
        ├── color_grid_widget.dart       # شبكة الألوان
        ├── game_header_widget.dart      # رأس الصفحة
        ├── game_over_dialog.dart        # حوار نهاية اللعبة
        └── success_dialog.dart          # حوار النجاح
```

### State Management Flow
```
[User Action] → [Event] → [BLoC] → [New State] → [UI Update]
```

## كيفية اللعب (How to Play)

1. **البداية**: تبدأ اللعبة تلقائيًا بعد فترة قصيرة من الدخول
2. **المشاهدة**: راقب تسلسل الألوان المضيئة بعناية
3. **الإعادة**: بعد انتهاء العرض، اضغط على الألوان بنفس الترتيب
4. **النجاح**: إذا كررت التسلسل بشكل صحيح، ستنتقل للجولة التالية بتسلسل أطول
5. **الفشل**: عند الخطأ، تنتهي اللعبة وتعرض النتيجة النهائية

## ملاحظات التطوير (Development Notes)

### لماذا SharedPreferences؟
تم اختيار SharedPreferences بدلاً من Hive للأسباب التالية:
- **البساطة**: لا نحتاج سوى لحفظ قيمة واحدة (أعلى نتيجة)
- **خفة الوزن**: SharedPreferences أخف وأسرع للبيانات البسيطة
- **متوفر مسبقًا**: مكتبة SharedPreferences موجودة في dependencies

### التحديات التقنية
1. **إدارة التوقيت**: استخدام Future.delayed لعرض التسلسل بشكل متزامن
2. **التحقق من التسلسل**: فحص فوري لكل ضغطة مع feedback سريع
3. **الرسوم المتحركة**: استخدام AnimatedBuilder و Transform.scale للتأثيرات
4. **التكامل**: دمج اللعبة في نظام Level Map الموجود
